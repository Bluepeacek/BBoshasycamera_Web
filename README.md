# 뽀샤시 사진관

사진을 찍으면 주름은 부드럽게, 피부는 환하게 다듬어서 갤러리에 바로 저장해 주는 웹 앱입니다.
사진은 폰 안에서만 처리되고 어디로도 전송되지 않습니다.

## 1. GitHub에 올려서 주소 만들기 (처음 한 번만)

1. GitHub에서 **New repository** → 이름은 `bosasi` 등 아무거나 → **Public(공개)** 선택 → Create
   - 무료 계정은 공개 저장소여야 주소가 만들어집니다. 사진 처리는 폰 안에서만 일어나서 공개해도 사진이 노출되지 않아요.
2. 저장소 화면에서 **uploading an existing file** 클릭 → 이 폴더 안의 파일 **7개를 전부** 끌어다 놓기 → **Commit changes**
   - `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `README.md`
3. 저장소 **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, 폴더: **/ (root)** → Save
4. 1~2분 기다린 뒤 Pages 화면 위쪽에 나오는 주소를 확인합니다.
   - 주소 모양: `https://내아이디.github.io/bosasi/`

## 2. 어머니 폰에 설치하기

1. 폰의 **Chrome**에서 위 주소를 엽니다. (카카오톡으로 주소를 보내 드리면 편해요)
2. 화면에 **"바탕화면에 앱으로 설치하기"** 버튼이 보이면 누릅니다.
   - 버튼이 안 보이면: Chrome 오른쪽 위 점 세 개(⋮) → **홈 화면에 추가** → **설치**
3. 이제 바탕화면의 분홍 하트 아이콘만 누르면 앱처럼 열립니다.

## 3. 쓰는 법

1. **사진 찍기**를 누르고 카메라로 찍은 뒤 확인(✓)을 누릅니다.
2. 잠깐 기다리면 뽀샤시하게 고쳐진 사진이 **갤러리에 자동 저장**됩니다.
3. 정도를 바꾸고 싶으면 "자연스럽게 / 뽀샤시 / 아주 뽀샤시"를 누르고, **다시 저장하기**를 누릅니다.

저장된 사진은 갤러리의 **'다운로드(Download)' 앨범**에 있습니다.
(웹 앱은 보안상 갤러리에 직접 쓰지 못하고 사진 파일을 내려받는 방식이라, 갤러리의 다운로드 앨범에 모입니다.)

## 고칠 때

파일을 고쳐서 다시 올린 뒤에는 `sw.js` 맨 위의 `bosasi-v1` 숫자를 `bosasi-v2`처럼 올려 주세요.
그래야 이미 설치한 폰들이 새 버전을 받아 옵니다.
